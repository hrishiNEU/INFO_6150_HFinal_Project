# 🎯 Hobby Hub

A full-stack web platform built with **React.js**, **Express.js**, **Redux**, **Socket.IO**, **MongoDB**, and **Tailwind CSS**, designed to connect users, admins, and business owners based on shared hobbies. Features include real-time communication, role-based access control, and community management tools.

## 🚀 Features

- 👥 **Role-Based Access System** — 5 distinct roles: Super Admin, Admin, Business User, Regular User, Guest
- 💬 **Real-Time Chat** — Powered by Socket.IO for seamless live interaction
- 🛠️ **Admin Tools** — Manage and moderate 20+ hobby communities
- 🔐 **Secure Data Handling** — User data encryption and password hashing with best practices
- 📦 **MongoDB Integration** — Stores user profiles, messages, and community data

## 🛠️ Tech Stack

- **Frontend**: React.js, Redux, Tailwind CSS
- **Backend**: Express.js, Node.js, REST APIs
- **Real-Time**: Socket.IO
- **Database**: MongoDB (with Mongoose)

## 📁 Project Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/hobby-hub.git
   cd hobby-hub
   ```

2. Install dependencies for both frontend and backend:
   ```bash
   cd client
   npm install
   cd ../server
   npm install
   ```
3. Create .env files for both client and server (see .env.example if available).

4. Run the development servers
